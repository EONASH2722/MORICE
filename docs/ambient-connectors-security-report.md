14. **Connector health.** NOT_CONFIGURED/CONNECTING/CONNECTED/DEGRADED/AUTH_EXPIRED/RATE_LIMITED/UNAVAILABLE/DISABLED states and lightweight cached kernel health. No startup account request.
15. **Webhook handling.** Actual signed loopback HTTP receiver; HMAC-SHA256, constant-time comparison, repository/account scoping, bounded body/backlog/deadline and body-hash replay protection. An external HTTPS relay is separate configuration.
16. **Polling.** Persisted revision cursor, newest 30 matching issues, deduplicated overlap and explicit truncation. Timing waits remain outside agent workers.
17. **Rate limiting.** Retry-After/exhaustion moves work to a future time; background call and action budgets plus bounded exponential backoff. External writes never retry blindly.
18. **Verification of external actions.** Created issue is independently retrieved and compared. HTTP success with a missing or mismatched object fails. All writes in validation went to an owned loopback fixture.
19. **Prompt-injection protection.** Provider/document content stays untrusted data. It cannot select capabilities, edit watch policy, issue approvals, grant scopes or enable security. Tokens and provider bodies cannot enter event envelopes.
20. **Ambient Event Runtime.** Persistent timing/rule extension to AutomationEngine and the same EventBus/AgentCoordinator, with no duplicate agent runtime.
21. **Event model.** Structured ids, source, time, severity, scoped references, trust, authorization context, dedupe, correlation and depth; bounded scalar envelope.
22. **TriggerEngine.** Existing automation gains deterministic condition watches and registered capability actions. Free-form semantic watches are explicitly unavailable.
23. **Trigger persistence.** SQLite watch configuration and action receipts survive restart; interrupted effects require review. Expired watches are removed on load.
24. **Condition watches.** Scalar comparison, source/project/device filters, static target node, expected outcome and matching/nonmatching validation. File scopes cannot be selected by external event text.
25. **Cooldowns.** Per-watch persisted last-run time suppresses repeat matches inside the configured interval; disabled and paused watches do not dispatch.
26. **Event dedupe.** 5,000 retained local event keys; signed bodies have a separate persistent 1,024-key fail-closed ledger per secret. Duplicate headers/body and restart are tested.
27. **Idempotency.** Durable action receipts and local notification receipts; atomic confirmation claims prevent two simultaneous exact approvals from dispatching one pending consequence twice. Interrupted writes never replay automatically. External provider idempotency is not invented.
28. **Loop prevention.** Bounded causal context through existing WorkerManager, per-watch causal keys, depth limit and per-minute budgets. An action emitting its own triggering event dispatches once.
29. **Scheduling.** One-time and recurring due times, minimum 60-second recurrence, expiration, pause and one deduplicated catch-up after an offline interval. No timer per watch or sleeping worker.
30. **Proactive notification behavior.** Only enabled matching watches notify; quiet periods, failure-only policy, minimum severity and explicit critical override. Existing local notification manager only; no external send or speech.
31. **Autonomy levels.** Notify, read/analyze, reversible local work and pending exact confirmation. External writes require level 3; no unrestricted autonomy level.
