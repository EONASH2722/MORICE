# Phase 11 release audit — MORICE 0.9.0

This is the preserved 0.9.0 audit. The [0.9.1 follow-up](followup-audit-0.9.1.md) records later user-reported UI repairs and the new preview release at a separate source fingerprint.

Local software acceptance completed 2026-10-15: **1,077 tests and 62 subtests pass in 398.39 seconds**. Exact current-source wheel/frozen parity, isolated-dependency launch and both installed EXE paths pass. [Current evidence and checksums](release-audit-evidence.json) bind these results to source `64e3ca3cc532d7f592103fcb7c2e15338c3575d80f06cca5a67429758f6ac8c9`. Authorized source/site publication is a separate final stage; no new public binary is claimed. Preexisting work, original models and user data are retained.

The audit distinguishes actual execution, controlled fixtures, static review, historical evidence and unavailable physical/provider checks. Decoration never represents real task progress. Current software verification does not certify arbitrary external applications, scientific experiments, physical devices or every model configuration.

Historical references to a model-free frozen candidate mean **no bundled GGUF/safetensors/generative weights**. The originally bundled Vosk speech model remains intentionally present. Fine scene contours now use native antialiased vector drawing; only diffuse light uses small cached rasters. The latest navigation/vector source supersedes earlier package fingerprints until its own matching gates pass.

### 5. Bugs discovered

The audit reproduced the invisible composer, oversized native maximize, redundant navigation, suppressed/indistinct motion, native icon painting overlapping worker GC, full 10,000-row result decoding before a 500-row display trim, and managed-process startup/cancellation gaps. Repairs retain the original runtime authorities. ### 6. Blocker bugs

The invisible composer and off-screen maximize were release blockers because users could not send a message. Required controls are now checked for visibility and containment in both the application rectangle and the monitor's usable rectangle. The previous geometry audit incorrectly skipped hidden controls; its acceptance result is explicitly superseded for this defect.

### 7. Critical bugs

No new reproducible permission bypass, execution-authority duplication or false-success path was established in the scoped source/runtime checks. This is a bounded finding, not a proof that all security defects are absent. Any failing current-source full-suite, package, native startup or cleanup check remains a gate rather than being explained away by the earlier green build.

### 8. High bugs

The surviving-window browser bridge repair preserves verified browsing after closing another window. Composer/maximize and duplicate navigation directly affect basic interaction and were prioritized over publication. Startup remains slower than the retained legacy constructor; its measured cost and synchronous window-creation pauses are retained as performance constraints, with no unsupported claim of universal smoothness.

### 9. Medium bugs

Glass lacked a named preset and themes previously shared nearly identical contours. LOW quality disabled the field entirely, making ordinary battery-constrained operation appear unanimated. Current themes have different geometry and closed motion cycles, a visible Theme menu and a bounded four-layer LOW scene. Explicit Reduced Motion continues to stop decoration.

### 10. Low bugs

The version test's literal 0.8.0 expectation was replaced with comparison against the authoritative version. Documentation distinguished earlier published binaries from the new source candidate. The repeated-install script now recognizes only its exact owned root runtime junction and handles its string target safely; unexpected links or paths still fail preflight.

### 11. Cosmetic bugs

Themes now vary in shape, corner treatment, material and movement as well as palette. Glass has reflective edges and procedural refraction, Amethyst has petal rosettes, Arctic has aurora curtains, and the other presets have separate motifs. These are authored decorative scenes; no face, eyes, borrowed video frames or replaced logo were introduced.
