# MORICE 0.9.0 — candidate notes

A renovated local desktop workspace integrates the existing runtime through one production window factory. The Core uses original rotating/lifting orbits and a procedural field, with authored pictograms, adaptive quality, Reduced Motion, searchable settings and focused workspaces. Spatial calculations use offline city data and deterministic WGS84 math.

Themes now differ in geometry, material and animation: Plasma, Prismatic Glass, Basalt, Crystal Bloom, Petal Garden, Star Atlas, Circuit Current, Kinetic Weave, Harmonic Braid, Aurora, Solar Corona and Resonance. Cached native vector geometry replaces scaled raster lines. Closed transforms and particle paths match at their position and velocity boundaries. A visible Theme menu exposes selection and animation controls. The message editor remains visible during native maximize/restore, including after visiting taller workspaces. Navigation appears once: a bottom launcher on Core or a left sidebar in a workspace.

The preceding phase extensions retain the shared Kernel, agents, verified actions, Builder, Research, Mesh, Ambient/Security, Media and permission/resource contracts. The Phase 11 audit verifies current-source packaging, lifecycle, version and public documentation separately.

This candidate is not a newly published binary release. Public Windows/Android 0.8.0 downloads remain earlier builds. Models are installed separately with their own licenses and resource requirements. Physical devices, fresh heavy generation and per-app graphics/compositor attribution remain constrained; no model guard or wake confidence threshold was lowered.

See renovation-report.md, release-audit-progress.md and the final audit report for measured results, corrected defects, artifacts and exact remaining gates.

Native icon painting uses a bounded high-DPI cache of the original authored artwork, avoiding Python icon-engine callbacks during worker garbage collection. Research result presentation reads at most 500 rows from the existing store while preserving complete exports and matching counts. Database readers close before JSON decoding; no journal-mode migration ships. Managed Windows process families use a private kill-on-close Job, exact initial-thread identity checks and a native thread query. Windows source installations require psutil; the existing media-tools extra remains compatible.
