## Performance and inherited limitation audit

The first 10,000-run audit exposed CPU admission starvation during parallel cheap
model batches. The final implementation uses the existing coordinator's sequential
option for those batches, leaving a CPU lease on multicore hosts. The completed
capacity run records 10,000 actual results in 16.981 s, real partial progress and
250 successful interactive echo/calculation samples. Configured worker bound is
four; cheap model execution uses one worker. No replacement scheduler or pool
was introduced. One-core and saturated-host resource limits remain explicit.

The exact original five Phase 2 limitations are accounted for in the completion
report. Supported embedded-browser navigation is verified; full semantic vision
is still unavailable. Shared observe/recover behavior is retained with provider
limits. Existing scheduler admission avoids adding worker-occupying long waits;
direct arithmetic bypass remains measured. No GPU speedup/VRAM or discovered
scientific hardware is claimed from registered budget descriptors.

The full-suite preview failure was traced to incidental biology keywords in file
paths. Explicit file preview now takes precedence; deterministic DNA/RNA/protein
path coverage passes without weakening the original preview assertion.
